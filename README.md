# Running of the Frenchie

A browser game: Chorizo the French bulldog runs the Pamplona encierro across 25 levels, from Calle Santo Domingo to the bullring.

Open `index.html` in a browser. Single file, no build step.

**Controls:** ← → or A / D to steer, hold Space (or the Charge button) to charge. Boop runners, grab water bowls for breath and churros for zoomies.
